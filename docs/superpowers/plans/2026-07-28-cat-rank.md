# Cat Rank Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Binance USDT perpetual chart-and-volume ranking API and Cat Rank dashboard tab.

**Architecture:** A Binance kline adapter supplies 4h/1d/1w candles to a pure scorer, then a 15-minute cache exposes ranked results through FastAPI HTML and JSON routes.

**Tech Stack:** Python 3.12, FastAPI, httpx, pytest, native HTML/CSS/JavaScript.

## Global Constraints

- Rank Binance USDT perpetuals only and show observation priority, never a buy instruction.
- Score volume trend (30), accumulation movement (25), support preservation (25), and breakout readiness (20).
- Exclude illiquid contracts and flag support failure or hostile movement.
